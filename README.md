# Pastimes-Clothing-Store

## Overview
Pastimes is an online web application that allows users to buy and sell second-hand branded clothing. The system provides a user-friendly interface for browsing, purchasing, and uploading clothing items.

## Features
- User registration and login
- Admin verification system
- Upload clothing items (seller)
- Browse products with images
- Shopping experience interface
- Database integration (MySQL)

## Technologies Used
- PHP
- MySQL
- HTML & CSS
- GitHub for version control

## How to Run
1. Place project in WAMP (www folder)
2. Import database using phpMyAdmin
3. Run createTable.php
4. Open in browser: http://localhost/Pastime
